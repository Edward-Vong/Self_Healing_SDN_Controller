Notes:
- Do not use `--run-saturation` (not a valid flag in this script).
- Saturation runs by default unless `--skip-saturation` is passed.

Current default behavior in run_all_tests.sh (fast profile):
- attack-delay defaults to 0
- baseline-control calibration stage is skipped by default
- threshold defaults to 50
- to restore the old baseline calibration stage, add: --run-baseline-control

Estimated wall-clock times:
- Quick run below (duration=90, skip sweeps): ~5-7 minutes
- Full default run (with saturation + sweeps): ~25-30 minutes
- If --run-baseline-control is enabled: add ~2 minutes

Quick iteration run (much faster, good for validation while debugging):
- attack-delay 0: attack starts immediately (no warmup wait per run)
- skip-baseline-control: skip the 180s threshold calibration run (uses fixed threshold=50)
- threshold 50: fixed detection threshold so baseline-control is not needed
- skip-sweeps: run only the 3 core comparison runs + baseline_no_attack

bash experiment_scripts/run_all_tests.sh \
  --skip-sweeps \
  2>&1 | tee run_all_quick.log

Full run (long, complete comparison and sweeps):

bash experiment_scripts/run_all_tests.sh 2>&1 | tee run_all.log
