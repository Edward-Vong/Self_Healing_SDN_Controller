Run from the controller node at the repository root.

This runs the full experiment suite using the topology values in
experiment_scripts/switches.conf. Each experiment run lasts 75 seconds:

- 15 seconds of normal traffic before the attack starts
- 45 seconds of attack traffic
- 15 seconds after the attack window for recovery and leftover flood traffic to clear

```bash
bash experiment_scripts/run_all_tests.sh \
  --duration 75 \
  --attack-delay 15 \
  --attack-length 45 \
  --clear-ovs off \
  2>&1 | tee run_all_75s.log
```

After it finishes, check:

```bash
cat results/last_run_status.txt
tail -n 80 run_all_75s.log
```
