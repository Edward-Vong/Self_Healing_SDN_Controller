Notes:
- Do not use `--run-saturation` (not a valid flag in this script).
- Saturation runs by default unless `--skip-saturation` is passed.

Current default behavior in run_all_tests.sh (fast profile):
- attack-delay defaults to 0
- baseline-control calibration stage runs by default
- if baseline-control is skipped and no --threshold is provided, threshold defaults to 300
- to skip baseline calibration for a quick run, add: --skip-baseline-control --threshold 50

Estimated wall-clock times:
- Quick run below (duration=90, skip sweeps): ~5-7 minutes
- Full default run (with saturation + rate + packet-size sweeps): ~30-35 minutes
- If --run-baseline-control is enabled: add ~2 minutes

Quick iteration run (much faster, good for validation while debugging):
- attack-delay 0: attack starts immediately (no warmup wait per run)
- skip-baseline-control: skip the 180s threshold calibration run (uses fixed threshold=50)
- threshold 50: fixed detection threshold so baseline-control is not needed
- skip-sweeps: run only the core comparison runs + baseline_no_attack

bash experiment_scripts/run_all_tests.sh \
  --skip-baseline-control \
  --threshold 50 \
  --skip-sweeps \
  2>&1 | tee run_all_quick.log

Full run (long, complete comparison and sweeps):

bash experiment_scripts/run_all_tests.sh 2>&1 | tee run_all.log

Packet-size sweep only context:
- The full sweep section now includes Scapy mitigation-on packet sizes: 64B, 256B, 512B.
- Defaults: --size-sweep-rate 1200 --size-sweep-sizes 64,256,512.
- Results are named like: size_64_scapy_mit_on, size_256_scapy_mit_on, size_512_scapy_mit_on.
- Summary plots are emitted as size_vs_*.png when at least two packet sizes complete.
- Use --skip-rate-sweep to run packet-size sweep without the rate sweep.

Example with explicit packet-size sweep values:

bash experiment_scripts/run_all_tests.sh \
  --skip-baseline-control \

  --skip-saturation \
  --skip-core \
  --skip-rate-sweep \
